# /movie-purchase - TOHOシネマズ映画チケット自動購入

BTC Lightning で V-Preca ギフトを購入し、Claude in Chrome で TOHOシネマズ vit の座席指定〜決済までを自動実行します。

## Instructions

このスキルが呼び出されたら、以下の手順で進めてください。

### Step 1: 説明を表示してユーザーの確認を待つ

まず以下を表示し、**ユーザーの「はい」を待ってから** 次に進んでください:

---

**BTC → 映画チケット自動購入フロー**

以下のステップを自動で実行します:

1. 上映情報の確認（/movie-search の結果を利用、または新規検索）
2. V-Preca ギフト購入（BTC Lightning → UseBitcoin.jp）
3. V-Preca カード情報取得（/vpreca-inquiry）
4. TOHOシネマズ vit で座席指定・決済（Claude in Chrome）
5. 予約完了通知

**決済ルート:**
```
BTC (Lightning) → UseBitcoin → V-Preca ギフト → vit VISA決済
```

**フォールバック決済（V-Preca が弾かれた場合）:**
```
BTC (Lightning) → UseBitcoin → au PAY ギフト → vit au PAY決済
```

**安全制限:**
- 映画チケット1枚: 通常 ¥1,900〜¥2,200
- V-Preca 購入は必要最低額で実行

続行しますか？ (はい / いいえ)

---

### Step 2: 購入条件の確認

ユーザーに以下を確認してください（引数で渡された場合はスキップ）:

1. **劇場名** — TOHOシネマズの劇場名（例: 新宿、六本木）
2. **映画タイトル** — 鑑賞したい映画
3. **鑑賞日時** — 日付と希望の上映回（例: 明日 19:00の回）
4. **枚数** — チケット枚数（デフォルト: 1枚）
5. **座席の好み**（任意） — 中央寄り、通路側、後方 など

```
チケット購入に必要な情報を入力してください。

1. 劇場名（例: 新宿）:
2. 映画タイトル:
3. 鑑賞日時（例: 明日 19:00）:
4. 枚数（デフォルト: 1枚）:
5. 座席の好み（任意）:
```

### Step 3: 上映スケジュール確認

Claude in Chrome で TOHOシネマズの上映スケジュールを確認します。

1. `navigate` で TOHOシネマズのスケジュールページにアクセス
2. 該当する映画・上映回の空席状況を確認
3. ユーザーに上映回を確認:

```
以下の上映回が見つかりました:

🎬 {映画タイトル} — TOHOシネマズ{劇場名}
  ① {時刻} {上映形式} {空席状況}
  ② {時刻} {上映形式} {空席状況}

どの回にしますか？
```

### Step 4: V-Preca ギフト購入

チケット代金分の V-Preca ギフトを BTC で購入します。

#### 4a. 必要金額の算出

```
チケット代金の算出:
  通常料金: ¥2,000 × {枚数}枚 = ¥{合計}
  → V-Preca 購入額: ¥{切り上げ額}（余裕を持って購入）
```

※ 料金はスクリーンタイプ（IMAX: +¥600, 4DX: +¥1,000, Dolby: +¥600 等）により変動。
  上映情報から正確な料金を取得できない場合は ¥2,500/枚 で見積もる。

#### 4b. ウォレット残高確認

1. `cashu_get_balance` で Cashu ecash 残高を確認
2. Ark が利用可能なら `ark_get_balance` も確認
3. 残高不足の場合は入金方法を案内して中断

#### 4c. V-Preca 購入実行

`usebitcoin_buy_gift_card` を呼び出す:
- `product`: `vpreca`
- `amount`: Step 4a で算出した金額

```
V-Preca ギフト購入中...
  金額: ¥{金額}
  Lightning invoice 取得中...
  Cashu で支払い中...
  完了！
```

#### 4d. V-Preca カード情報取得

`vpreca_inquiry` を呼び出してフルカード情報を取得:
- `giftCode`: 購入時に返却されたギフトコード
- `cardLast4`: 購入結果のカード番号下4桁

```
V-Preca カード情報取得中...
  カード番号: XXXX XXXX XXXX XXXX
  有効期限: MM/YY
  CVV: XXX
  残高: ¥X,XXX
  → 決済に使用します
```

### Step 5: vit で座席指定・決済（Claude in Chrome）

Claude in Chrome を使って TOHOシネマズ vit でチケットを購入します。

#### 5a. vit ログイン（ゲスト利用）

1. `navigate` で vit のチケット購入ページにアクセス
   - URL: `https://hlo.tohotheater.jp/net/ticket/TNPI2040J03.do`
   - または上映スケジュールページから「購入する」ボタンをクリック
2. ログインは不要（ゲスト購入を選択）

#### 5b. 上映回選択

1. 該当する映画・上映回を選択
2. `read_page` でページ内容を確認しながら操作
3. 券種を選択（一般、大学生、小人 等）
4. 枚数を指定

#### 5c. 座席選択

1. 座席選択画面で空席マップを `read_page` で読み取る
2. ユーザーの好みに応じて座席を選択:
   - **中央寄り**: 中央ブロックの中段を優先
   - **通路側**: 各ブロックの端席を優先
   - **後方**: 後方列を優先
   - **指定なし**: 中央付近の良席を自動選択
3. `computer` ツールで座席をクリック

```
座席選択中...
  座席マップを読み取っています...
  選択: {列}{番号}（{位置の説明}）
  確定しますか？ (はい / いいえ)
```

**重要: 座席選択後、ユーザーに確認を取ってから次に進むこと。**

#### 5d. 決済情報入力

1. 決済方法で「クレジットカード」を選択
2. `form_input` で V-Preca のカード情報を入力:
   - カード番号: Step 4d で取得した番号
   - 有効期限: Step 4d で取得した期限
   - セキュリティコード: Step 4d で取得した CVV
3. メールアドレスを入力（ユーザーに確認）

#### 5e. 購入確定

1. 注文内容確認画面で内容を `read_page` で読み取り表示
2. **ユーザーの最終確認を必ず取る**:

```
=== 注文内容確認 ===
  映画: {タイトル}
  劇場: TOHOシネマズ{劇場名}
  日時: {日付} {時刻}〜
  座席: {座席番号}
  料金: ¥{合計金額}
  決済: V-Preca (VISA)

この内容で購入を確定しますか？ (はい / いいえ)
```

3. ユーザーが「はい」と回答したら購入ボタンをクリック

### Step 6: 購入完了・結果表示

```
=== 映画チケット購入完了 ===
  映画: {タイトル}
  劇場: TOHOシネマズ{劇場名}
  日時: {日付} {開始時刻}〜{終了時刻}
  座席: {座席番号}
  チケット料金: ¥{料金}
  BTC 支払額: {sats} sats
  支払方法: Cashu → V-Preca
  予約番号: {番号}

入場方法:
  劇場の自動発券機で予約番号を入力してチケットを受け取ってください。
  ※ QRコード入場に対応している劇場もあります。
```

## フォールバック: au PAY 決済ルート

Step 5d で V-Preca が弾かれた場合（プリペイドカード非対応エラー）:

1. ユーザーに通知:
```
V-Preca での決済が拒否されました。
au PAY ルートに切り替えますか？ (はい / いいえ)
```

2. `usebitcoin_buy_gift_card` で au PAY ギフトカードを購入:
   - `product`: `aupay`
   - `amount`: チケット代金以上の金額

3. au PAY アプリでギフトカードをチャージ（ユーザーに操作を依頼）

4. vit で au PAY 決済を選択

※ au PAY ルートはユーザーのスマートフォン操作が必要なため半自動になります。

## Error Handling

- **上映回が見つからない**: 他の日程・劇場を提案
- **座席が全て埋まっている**: 他の上映回を提案
- **V-Preca 残高不足**: 追加の V-Preca を購入するか確認
- **決済エラー**: フォールバック（au PAY）を提案
- **vit ページ操作エラー**: スクリーンショットを確認し、手動操作の案内に切り替え
- **各ステップでエラーが発生した場合**: 即座に中断し、エラー内容を日本語で報告

## Prerequisites

以下の MCP サーバーが接続済みであること:

1. **purchasing-agent** — V-Preca 購入・照会、Cashu/Ark ウォレット操作
2. **Claude in Chrome** — TOHOシネマズ vit のブラウザ操作

未接続の場合は各 MCP サーバーの設定を案内してください。

## 典型的なワークフロー

```
1. /movie-search で上映スケジュールを確認
   → 映画名・上映時間・空席状況を表示

2. /movie-purchase で自動購入
   → BTC → V-Preca → vit で座席指定〜決済を自動実行
   → 予約番号を取得

3. 劇場で自動発券機にて入場券を受け取り
```
