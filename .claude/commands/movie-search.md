# /movie-search - TOHOシネマズ上映スケジュール検索

Claude in Chrome を使って TOHOシネマズの上映スケジュールを検索し、映画・劇場・上映時間の情報を取得します。

## Instructions

このスキルが呼び出されたら、以下の手順で進めてください。

### Step 1: 検索条件の確認

ユーザーに以下を確認してください（引数で渡された場合はスキップ）:

1. **劇場名** — TOHOシネマズの劇場名（例: 新宿、六本木、日比谷、渋谷）
2. **鑑賞日** — 日付（例: 今日、明日、2026-04-20）
3. **映画タイトル**（任意） — 特定の映画を探す場合

```
TOHOシネマズの上映スケジュールを検索します。

1. 劇場名（例: 新宿、六本木）:
2. 鑑賞日（例: 今日、明日、4/20）:
3. 映画タイトル（任意。全作品を見たい場合は空欄）:
```

### Step 2: TOHOシネマズサイトにアクセス

Claude in Chrome の `navigate` ツールで TOHOシネマズのスケジュールページにアクセスします。

**URL パターン:**
- 劇場一覧: `https://hlo.tohotheater.jp/net/schedule/TNPI3090J01.do`
- 劇場コード（主要劇場）:
  - 新宿: `076`
  - 六本木ヒルズ: `073`
  - 日比谷: `085`
  - 渋谷: `064`
  - 池袋: `006`
  - 上野: `066`
  - 二子玉川: `043`
  - 府中: `028`
  - 立川立飛: `059`
  - 海老名: `035`
  - ららぽーと横浜: `048`
  - なんば: `052`
  - 梅田: `053`
  - 西宮OS: `060`

**アクセス手順:**
1. `navigate` で TOHOシネマズ上映スケジュールページを開く
2. `read_page` または `get_page_text` でページ内容を取得
3. 上映スケジュール情報をパースする

### Step 3: 上映情報の表示

取得した上映情報を以下のフォーマットで表示:

```
=== TOHOシネマズ {劇場名} — {日付} の上映スケジュール ===

🎬 {映画タイトル1}
   {上映形式（通常/IMAX/4DX/Dolby等）}
   ① {開始時刻}〜{終了時刻}  {空席状況}
   ② {開始時刻}〜{終了時刻}  {空席状況}
   ...

🎬 {映画タイトル2}
   ...
```

**空席状況の表示:**
- ◎ 残席あり
- △ 残りわずか
- × 満席
- — 販売前

### Step 4: 次のアクションを提案

```
チケットを購入しますか？
→ /movie-purchase で自動購入できます。
  映画名と上映回を指定してください。
```

## Error Handling

- **劇場名が見つからない場合**: TOHOシネマズの劇場一覧を表示して選択してもらう
- **ページ読み込み失敗**: リトライ後、手動で `https://www.tohotheater.jp/` にアクセスするよう案内
- **上映情報が取得できない場合**: ページ構造の変更を疑い、`read_page` の結果を確認して対応

## Prerequisites

Claude in Chrome MCP サーバーが接続済みであること。

## 典型的なワークフロー

```
1. /movie-search で上映スケジュールを確認
   → 映画名・上映時間・空席状況を表示

2. /movie-purchase で座席指定〜決済まで自動実行
   → BTC Lightning → V-Preca → vit で決済
```
