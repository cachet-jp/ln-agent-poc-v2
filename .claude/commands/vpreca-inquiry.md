# /vpreca-inquiry - V-Preca カードの使い方・照会

UseBitcoin.jp で V-Preca ギフトを購入した後、その**ギフトコード**をどう使うかを案内し、必要ならカード照会まで導きます。

V-Preca ギフトの使い道は 2 つあります:

1. **V-Preca アプリにチャージ** — アプリのアカウントに残高としてチャージして繰り返し使う
2. **アカウントレスでカード番号を発行** — アカウント登録せず、その場でカード番号・有効期限・CVV を発行してネット決済に使う

## Instructions

### Step 1: 入力の確認

ユーザーに以下を確認してください（購入直後で既に分かっている場合・引数で渡された場合はスキップ）:

1. **ギフトコード** — UseBitcoin 購入時に取得したコード（例: `EXAMPLExxxxx123`）
2. **カード番号下4桁** — 同じく購入結果に含まれる4桁の数字

### Step 2: 使い道を尋ねる（if文1）

購入したギフトコードを表示したうえで、次のように尋ねてください:

```
購入した V-Preca ギフトコードの使い道を選んでください。

1. V-Preca アプリにチャージする（アカウントに残高としてチャージ）
2. アカウントレスでカード番号を発行する（その場でネット決済用の番号を取得）

1 または 2 を選んでください。
```

---

### 選択 1 — V-Preca アプリにチャージ

アプリDL〜チャージの動線を丁寧に案内してください:

```
V-Preca アプリにチャージする手順:

1. V-Preca アプリ（新アプリ）をインストール
   - 公式案内: https://vpc.lifecard.co.jp/
   ※ 2024年5月の刷新後は、アプリDL後にアカウント登録が必要です。
     旧アプリではチャージできません。
2. アプリでアカウント登録 → ログイン
3. 下部メニューの「チャージ」→「ギフトコード」を選択
4. ギフトコードとカード番号下4桁を入力してチャージ
   - チャージ方法の詳細: https://vpc.lifecard.co.jp/guide/charge.html
```

案内のあと、**もう一度購入したギフトコードを丁寧に再表示**してください（ユーザーがアプリに入力できるように）:

```
入力に使うギフトコード:
  ギフトコード   : <giftCode>
  カード番号下4桁 : <cardLast4>
```

ここで完了です。`vpreca_inquiry` は呼ばないでください。

---

### 選択 2 — アカウントレスでカード番号を発行（既定の動線）

まず、これが**規約同意を伴う本人操作**であることを説明します:

```
アカウントレスでカード番号を発行するには、V-Preca の照会ページで
利用規約を確認・同意し、ギフトコードと下4桁を入力する必要があります。

照会ページをブラウザで開きますか？ (はい / いいえ)
```

#### 「はい」の場合

`vpreca_open_inquiry_page` を呼び出し、ユーザーの既定ブラウザで照会ページを開きます。

- `opened: true` のとき — ブラウザを開けています。**ここで待機モードに入ってください**:

  ```
  照会ページをブラウザで開きました。
  ページで利用規約を確認・同意し、ギフトコードと下4桁を入力すると
  カード番号・有効期限・CVV・残高が表示されます。

  確認が終わったら声をかけてください。購入したギフトコードはこちらで保持しています。
  ```

  そのままユーザーの次の発言を待ちます（自動でタイマーは動きません）。ユーザーが戻ってきたら、必要に応じて**ギフトコードを再表示**して手助けしてください。コードやカード番号をローカルに保存することはしません。

- `opened: false` のとき — ブラウザを開けなかったので、レスポンスの `url` を案内し、手動で開いてもらってください。

#### 「いいえ」の場合

照会ページの URL と、入力に使うギフトコード・下4桁を提示して終了します。ユーザーが自分のタイミングで開けるようにします。

```
照会ページ: https://vpclogin.lifecard.co.jp/web/vpreca/vpreca_gift_inquiry_terms_agreement
  ギフトコード   : <giftCode>
  カード番号下4桁 : <cardLast4>
```

---

### （opt-in）エージェントによる照会代行

ユーザーが**明示的に「ブラウザは使わず、代わりに取得して」と希望した場合のみ**、`vpreca_inquiry` を使えます。このツールは**エージェントが利用規約に自動同意して**カード情報を取得するため、既定では使いません。使う前に必ずこの旨を伝えてください:

```
※ この方法ではエージェントが利用規約に自動同意してカード情報を取得します。
  ご自身で規約を確認したい場合は、照会ページを開く方法をご利用ください。
```

代行実行する場合:

- `vpreca_inquiry` を `giftCode` / `cardLast4` で呼び出す
- 結果表示時は、**カード番号より前に** レスポンスの `terms_url` / `notice` を必ず提示する:

```
※ このリンクは V-Preca の利用規約ページです:
  https://vpclogin.lifecard.co.jp/web/vpreca/vpreca_gift_inquiry_terms_agreement

=== V-Preca カード情報 ===
  カード番号 : XXXX XXXX XXXX XXXX
  有効期限   : MM/YY
  CVV        : XXX
  残高       : ¥X,XXX
  カード名義 : VPRECA
```

```
カード番号・有効期限・CVV をコピーしてご利用ください。
※ V-Preca はネット決済専用です。実店舗では使えません。
```

## Error Handling

- **照会失敗（ページ構造変更）**: 「Lifecard のサイト構造が変更された可能性があります。手動で照会ページにアクセスしてください」と案内
- **ギフトコード無効**: 「ギフトコードが無効か既に使用済みです。UseBitcoin の購入履歴をご確認ください」と案内
- **タイムアウト**: リトライするか確認してから再実行

## Prerequisites

purchasing-agent MCP サーバーが接続済みであること。未接続の場合:

```bash
cd purchasing-agent
pnpm install

# Claude Code に登録:
claude mcp add purchasing-agent -- npx tsx src/server.ts
```

## 典型的なワークフロー

```
1. /cashu-purchase で V-Preca を購入
   → ギフトコードとカード番号下4桁が返却される

2. /vpreca-inquiry で使い道を選択
   → 1: アプリにチャージ / 2: アカウントレスでカード番号を発行

3. 選択 2 → 照会ページを既定ブラウザで開き、本人が規約同意・コード入力
   → フルカード番号・有効期限・CVV・残高が表示される
```
