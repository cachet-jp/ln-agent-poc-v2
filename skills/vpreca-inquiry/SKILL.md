# vpreca-inquiry

V-Preca ギフトコードの使い道は 2 つある。**どちらかをユーザーに選ばせるのが最初の仕事**で、勝手に照会を始めない。

1. **V-Preca アプリにチャージ** — アプリのアカウントに残高としてチャージして繰り返し使う
2. **アカウントレスでカード番号を発行** — 登録せずカード番号・有効期限・CVV を発行してネット決済に使う

## 0. 前提: purchasing-agent 拡張が必要

このスキルは MCP サーバー `purchasing-agent` のツールを呼ぶ。goose に未登録なら**ツールが無いので先に登録する**。

```yaml
# ~/.config/goose/config.yaml の extensions: 配下に追加
  purchasing-agent:
    enabled: true
    type: stdio
    name: purchasing-agent
    cmd: bash
    args:
    - -ilc
    - cd /Users/kohei/work/ln-agent-poc-v2/purchasing-agent && exec pnpm dev
    envs:
      NODE_ENV: development
    timeout: 300
    description: Bitcoin Lightning でギフトカード等を購入する（Cashu / UseBitcoin / Bitrefill / V-Preca）
    bundled: false
```

**ツール名は環境で変わる**。`vpreca_open_inquiry_page` そのままか、`purchasing-agent__vpreca_open_inquiry_page` のように拡張名で前置されることがある。ハードコードせず、手元で使えるツール一覧から `vpreca_` を含むものを探して呼ぶ。見つからなければ「purchasing-agent 拡張が未登録」と報告して止まる。推測で別のツールを代用しない。

## 1. 入力の確認

購入直後で既に分かっている場合・引数で渡された場合はスキップ。

| 項目 | 例 |
|---|---|
| ギフトコード | `EXAMPLExxxxx123` |
| カード番号下4桁 | `1234` |

## 2. 使い道を尋ねる

ギフトコードを表示したうえで尋ねる。

```
購入した V-Preca ギフトコードの使い道を選んでください。

1. V-Preca アプリにチャージする（アカウントに残高としてチャージ）
2. アカウントレスでカード番号を発行する（その場でネット決済用の番号を取得）

1 または 2 を選んでください。
```

## 3-1. 選択 1 — アプリにチャージ

```
V-Preca アプリにチャージする手順:

1. V-Preca アプリ（新アプリ）をインストール
   - 公式案内: https://vpc.lifecard.co.jp/
   ※ 2024年5月の刷新後は、アプリDL後にアカウント登録が必要です。
     旧アプリではチャージできません。
2. アプリでアカウント登録 → ログイン
3. 下部メニューの「チャージ」→「ギフトコード」を選択
4. ギフトコードとカード番号下4桁を入力してチャージ
   - チャージ方法の詳細: https://vpc.lifecard.co.jp/guide/charge.html
```

案内のあと、ユーザーがアプリに入力できるよう**ギフトコードを再表示**する。

```
入力に使うギフトコード:
  ギフトコード   : <giftCode>
  カード番号下4桁 : <cardLast4>
```

ここで完了。`vpreca_inquiry` は呼ばない。

## 3-2. 選択 2 — アカウントレスでカード番号を発行（既定の動線）

これが**規約同意を伴う本人操作**であることを先に説明する。

```
アカウントレスでカード番号を発行するには、V-Preca の照会ページで
利用規約を確認・同意し、ギフトコードと下4桁を入力する必要があります。

照会ページをブラウザで開きますか？ (はい / いいえ)
```

**「はい」** → `vpreca_open_inquiry_page` を呼ぶ（ユーザーの既定ブラウザで開く）。

- `opened: true` — **待機モードに入る**。自分でタイマーを回したりポーリングしたりしない。

  ```
  照会ページをブラウザで開きました。
  ページで利用規約を確認・同意し、ギフトコードと下4桁を入力すると
  カード番号・有効期限・CVV・残高が表示されます。

  確認が終わったら声をかけてください。購入したギフトコードはこちらで保持しています。
  ```

  ユーザーが戻ってきたら、必要に応じてギフトコードを再表示して手助けする。コードやカード番号をローカルに保存しない。

- `opened: false` — レスポンスの `url` を案内し、手動で開いてもらう。

**「いいえ」** → URL と入力値を提示して終了。ユーザーのタイミングに任せる。

```
照会ページ: https://vpclogin.lifecard.co.jp/web/vpreca/vpreca_gift_inquiry_terms_agreement
  ギフトコード   : <giftCode>
  カード番号下4桁 : <cardLast4>
```

## 4. （opt-in）エージェントによる照会代行

ユーザーが**明示的に「ブラウザは使わず代わりに取得して」と言った場合のみ** `vpreca_inquiry` を使う。このツールは**エージェントが利用規約に自動同意して**カード情報を取得するため既定では使わない。使う前に必ず伝える。

```
※ この方法ではエージェントが利用規約に自動同意してカード情報を取得します。
  ご自身で規約を確認したい場合は、照会ページを開く方法をご利用ください。
```

`giftCode` / `cardLast4` で呼び、結果表示時は**カード番号より前に** `terms_url` / `notice` を必ず出す。

```
※ このリンクは V-Preca の利用規約ページです:
  https://vpclogin.lifecard.co.jp/web/vpreca/vpreca_gift_inquiry_terms_agreement

=== V-Preca カード情報 ===
  カード番号 : XXXX XXXX XXXX XXXX
  有効期限   : MM/YY
  CVV        : XXX
  残高       : ¥X,XXX
  カード名義 : VPRECA
```

```
カード番号・有効期限・CVV をコピーしてご利用ください。
※ V-Preca はネット決済専用です。実店舗では使えません。
```

## 5. 失敗したときの切り分け

照会ページが開けない／`vpreca_inquiry` が失敗したら、**原因を決めつけずに `vpreca-status` スキルで切り分ける**。

```
/usr/bin/python3 -I /Users/kohei/.claude/skills/vpreca-status/check.py
```

| 出力 | 意味 | 言うこと |
|---|---|---|
| `service: up` かつ `reachable_from_here: false` | サービスは稼働、こちらの出口 IP が WAF で 403 | 「VPN を切ってから開いてください」 |
| `service: maintenance` / `down` | ライフカード側が停止中 | 待つしかない。再開告知の日付を添える |
| `service: up` かつ `reachable_from_here: true` | 経路は正常 | ギフトコード無効/使用済みを疑う |

`vpclogin.lifecard.co.jp` の **403 はメンテナンスではない**。VPN・データセンター IP は無言で弾かれる。ローカルのブラウザ（agent-browser、ヘッドレス Chrome）は同じ出口 IP を使うので、ブラウザを変えても回避できない。

その他:

- **ページ構造変更で照会失敗** — 「Lifecard のサイト構造が変更された可能性があります。手動で照会ページにアクセスしてください」と案内
- **ギフトコード無効** — 「ギフトコードが無効か既に使用済みです。UseBitcoin の購入履歴をご確認ください」と案内
- **タイムアウト** — リトライするか確認してから再実行。黙って繰り返さない

## 6. やらないこと

- 規約同意のチェックを勝手に入れて「次へ」を押さない。同意はユーザー本人の操作。
- カード番号・CVV・ギフトコードをファイルやメモリに保存しない。会話に出すのは本人に見せるときだけ。
- カード情報を外部サービス（リレー、要約 API、スクリーンショット共有など）に送らない。
- 選択 1 を選んだ人に対して `vpreca_inquiry` を呼ばない。

## 典型的なワークフロー

```
1. cashu-purchase で V-Preca を購入
   → ギフトコードとカード番号下4桁が返る

2. このスキルで使い道を選択
   → 1: アプリにチャージ / 2: アカウントレスでカード番号を発行

3. 選択 2 → 照会ページを既定ブラウザで開き、本人が規約同意・コード入力
   → フルカード番号・有効期限・CVV・残高が表示される
```

Claude Code 向けの同内容のスラッシュコマンドが `.claude/commands/vpreca-inquiry.md` にある。手順を直すときは両方を直す。
